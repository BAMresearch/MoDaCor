# Citation

When citing the software, identify the exact MoDaCor release or Git commit used
and link to <https://github.com/BAMresearch/MoDaCor>.

The modular data-correction concepts are described in:

> B. R. Pauw et al., “The modular small-angle X-ray scattering data correction
> sequence,” *Journal of Applied Crystallography* (2017),
> <https://doi.org/10.1107/S1600576717015096>.

Use a release-specific software DOI if one is published in future release
metadata. This documentation does not invent or substitute a DOI for the
software.

Instrument example data have separate authorship, facility acknowledgements,
licenses, and citations in
[MoDaCor-examples](https://github.com/BAMResearch/MoDaCor-examples).
